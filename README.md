# 🏋️ FitLog 

## 📝 Description
FitLog is a modern, dark-themed fitness tracking web application designed to help users organize their daily exercise routines. Users can browse a comprehensive workout library, have a personalized "Today's Plan," save favorite exercises for later, and seamlessly manage their fitness journey with real-time tracking and sorting features.

## 🛠️ Technologies Used
* **Framework:** Next.js (React)
* **Language:** TypeScript
* **Styling:** Tailwind CSS & DaisyUI
* **State Management:** React Context API
* **Notifications:** React Toastify
* **Icons/Assets:** Heroicons / Custom SVGs

## ✨ 5 Key Features
1. **Personalized Daily Plans:** Easily add, track, and complete daily routines within the dedicated "Today's Plan" dashboard.
2. **Saved Workout Library:** Bookmark and manage favorite exercises in a separate "Saved" tab for quick and easy access later.
3. **Dynamic Sorting System:** Instantly sort workout lists across all tabs by duration (minutes), calories burned, or user rating.
4. **Interactive Action Controls:** Seamlessly mark workouts as "Done" or remove them from your lists, complete with real-time UI updates and success toast notifications.
5. **Modern Responsive UI:** A fully custom, responsive dark-mode interface accented with high-contrast neon highlights for a premium user experience across all devices.
